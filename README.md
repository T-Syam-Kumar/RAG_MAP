# RAG Field Guide

A responsive, accessible, and interactive HTML guide to **Retrieval-Augmented Generation (RAG)**. This resource explains the complete RAG pipeline, evaluation metrics, advanced retrieval techniques, production considerations, common pitfalls, and practical implementation choices.

## Features

- Clear explanation of the complete RAG pipeline
- Pipeline stages covering ingestion, chunking, embedding, indexing, retrieval, reranking, generation, and evaluation
- RAG evaluation metrics and quality considerations
- Advanced RAG techniques
- Production-readiness guidance
- Common pitfalls and troubleshooting notes
- Quick-reference recommendations
- Responsive layout for desktop and mobile screens
- Dark mode and light mode
- Search and filter functionality
- Expand all and collapse all controls
- Print-friendly layout
- Reading progress indicator
- Back-to-top button
- Keyboard focus styles and skip navigation link
- Reduced-motion support for accessibility
- Reset view option

## Getting Started

### 1. Download or Clone the File

Keep the following files in the same folder if you are using the guide locally:

```text
rag-field-guide-improved.html
README.md
```

### 2. Open the Guide

Double-click `rag-field-guide-improved.html`, or open it in a browser such as:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

No backend, database, package installation, or build process is required.

## How to Use

### Theme Toggle

Use the **Dark mode / Light mode** button to switch between display themes.

### Search

Enter a keyword in the search field to find relevant sections. Matching sections are displayed, and relevant expandable sections are opened automatically.

### Expand and Collapse Sections

- Select **Expand all** to open all expandable sections.
- Select **Collapse all** to close them.
- Use **Reset view** to return to the default reading state.

### Print

Select the **Print** button to print the guide or save it as a PDF through your browser's print dialog.
